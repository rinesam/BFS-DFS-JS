Breadth-first search vs Depth-first search
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Kjo temë prezanton një aplikacion në ueb për eksplorimin e labirinteve, i cili jo vetëm që gjeneron labirinte komplekse, por gjithashtu përfshin algoritme të avancuara të gjetjes së rrugës për zgjidhjen e labirinteve. Ndryshe nga gjeneratorët tradicionalë të labirinteve, ky aplikacion tejkalon kufijtë duke integruar karakteristika interaktive dhe vizualizimin në kohë reale të algoritmeve, duke e bërë atë një kombinim unik të teknologjisë dhe argëtimit.
Qendra e kësaj teme është përqendruar në përdorimin inovativ të teknologjive në ueb - JavaScript - për të ndërtuar një aplikacion që shkon përtej thjesht gjenerimit të labirinteve. Ajo hyn në sferat e kompleksitetit algoritmik dhe dizajnit të përvojës së përdoruesit. Aplikacioni ofron një varg opsionesh të personalizimit, duke lejuar përdoruesit të përshtatin kompleksitetin, madhësinë dhe strategjitë e zgjidhjes së labirinteve, duke ofruar kështu një përvojë të personalizuar. Ky projekt gjithashtu përqendrohet në analizimin e ndërveprimit të përdoruesit me aplikacionin, duke studiuar mënyrën se si ndërfaqja dhe opsionet e ndryshme ndikojnë në përvojën e përdoruesit dhe efikasitetin e mësimit.
Një aspekt i rëndësishëm i këtij projekti është krahasimi i detajuar midis dy algoritmeve themelore të zgjidhjes së labirinteve: Kërkimi i Gjerë i Parë (BFS) dhe Kërkimi i Thellë i Parë (DFS). Aplikacioni jo vetëm zbaton këto algoritme, por gjithashtu tregon vizualisht procesin e tyre, duke ofruar një pamje të thellë në ndryshimet dhe efikasitetet e tyre operacionale. Kjo është veçanërisht e dobishme për qëllime arsimore, pasi ofron një aplikim praktik të koncepteve teorike në botën reale.

This project introduces a web application for exploring mazes, which not only generates complex labyrinths but also includes advanced pathfinding algorithms for maze solving. Unlike traditional maze generators, this application pushes boundaries by integrating interactive features and real-time visualization of algorithms, making it a unique combination of technology and entertainment.
The focus of this theme is on the innovative use of web technologies - JavaScript - to build an application that goes beyond mere maze generation. It delves into the realms of algorithmic complexity and user experience design. The application offers a range of customization options, allowing users to adjust the complexity, size, and solving strategies of the mazes, thereby providing a personalized experience. This project also focuses on analyzing user interaction with the application, studying how the interface and various options affect the user experience and the effectiveness of learning.
An important aspect of this project is the detailed comparison between two fundamental maze-solving algorithms: Breadth-First Search (BFS) and Depth-First Search (DFS). The application not only implements these algorithms but also visually demonstrates their process, offering a deep insight into their operational differences and efficiencies. This is especially useful for educational purposes, as it provides a practical application of theoretical concepts in the real world.
